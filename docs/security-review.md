## شروط التحقق في بيئة التشغيل

- شغّل IIS عبر HTTPS، وفعّل Windows Authentication وعطّل Anonymous Authentication. تحقق من رفض الزائر والمستخدم المصادق عليه خارج المجموعة، ونجاح العضو المصرح له على الصفحة ونقطتي JSON.
- أعطِ هوية التطبيق صلاحيات قراءة محدودة على حقول SQL Server المطلوبة. تحقق من شهادة SQL Server ومن تعذر الكتابة بحساب التطبيق.
- اختبر ما إذا كان وصول المجموعة إلى جميع المناطق والخدمات يطابق سياسة المؤسسة. طبّق ضوابط على مستوى الصفوف إذا اقتضت السياسة تقييد النطاق حسب المنطقة أو الفريق.
- تحقق في بيئة تشغيل معزولة من سلوك الطلبات المتكررة وحجم الاستعلامات الشهرية، خصوصًا أن كل تحديث يجمع الصفوف المطابقة. نفّذ [اختبارات قبول الأعمال](requirements-traceability.md) ببيانات مصرح بها.

المراجعة ثابتة. يلزم التحقق من المصادقة وسياسة الوصول والاتصال بقاعدة البيانات في Windows/IIS قبل الاعتماد التشغيلي. [OWASP ASVS](https://asvs.owasp.org/) · [GitHub Actions Secure Use](https://docs.github.com/en/actions/reference/security/secure-use)
