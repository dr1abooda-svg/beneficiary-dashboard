# مطابقة متطلبات لوحة المتابعة مع المرحلة الأولى

تستند هذه المطابقة إلى وثيقة «مواصفات ومتطلبات بناء لوحات متابعة وتحليل مشاركات المستفيدين» المؤرخة في نوفمبر 2026. يغطي المستودع اللوحة التشغيلية الأولى على ASP.NET MVC 5. تصف الوثيقة أيضًا خيارات تنفيذ وتحليلات في Power BI.

| البند | تنفيذ المرحلة الأولى | معيار القبول |
|---|---|---|
| COM-01، COM-02 | فلاتر الشهر والقناة والمنطقة والخدمة، وزر إعادة الضبط. الضغط على مخطط القنوات يطبق فلتر القناة. يبدأ العرض بأحدث شهر فيه بيانات. | UAT-1-01. اختبر جميع الفلاتر. حسم الافتراضي المطلوب للشهر الحالي واعتماد نطاق التفاعل بين الرسوم. |
| D1-V01 | إجمالي التذاكر، الإغلاق، الالتزام، الرضا والبطاقات الديناميكية للقنوات الموجودة. مقام SLA هو التذاكر المغلقة ذات التواريخ الصالحة والموعد المعروف. | اعتمد معرفات القنوات الرسمية وطريقة التعامل مع الموعد المفقود. تتطلب الوثيقة الرجوع إلى `Sup_GroupService.MaxmumDays` عند غياب `ExpectDate`. |
| D1-V02 | توزيع القنوات على أساس بيانات الفترة. | UAT-1-02. طابق مجموع القنوات مع الإجمالي. اعتمد قاعدة إظهار البريد الإلكتروني «غير مفعلة» قبل يونيو 2026. |
| D1-V03 | أعمدة يومية تشمل أيام الشهر التي سجلت صفرًا، وملخص للمتوسط وأعلى يوم وأدناه. | UAT-1-04. طابق الإجمالي اليومي مع الفترة وأكّد قاعدة إدراج الأيام الصفرية. وثّق توقيت المصدر قبل تطبيق حدود اليوم والشهر بتوقيت الرياض. |
| D1-V04 | يعرض التطبيق حالات المصدر كما هي ويحسب عددها ونسبتها. | UAT-1-03. طابق مجموع الحالات مع الإجمالي ضمن الفلاتر نفسها واعتمد قاموس الحالات الثلاث. |
| D1-V05، COM-03 | أحدث عشر تذاكر بترتيب وقت الإنشاء ثم الرقم تنازليًا. حقل النوع يعرض تسمية `Ticket_Level`. تعرض اللوحة وقت الاستعلام وأحدث وقت لإنشاء تذكرة. | UAT-1-05. افحص الترتيب والحقول واعتمد قاموس أنواع المشاركات ووقت تحديث البيانات من المصدر عند توفره. |
| COM-04، COM-05 | يعتمد العد على مفتاح `Ticket.ID` والربط بجداول التوصيف. يقتصر الوصول على مجموعة Windows المصرح لها، وتقتصر الاستجابة على الحقول التشغيلية. | اختبر التفرد، وصلاحية التواريخ، وتسويات المجاميع، ووصول المستخدم غير المصرح له. احسم الحاجة إلى تقييد صفوف البيانات حسب المنطقة أو الفريق. |
| COM-06 إلى COM-08 | واجهة عربية RTL مع تنسيق للأعداد والنسب. | اختبر لوحة المفاتيح، والهاتف، ودقة التنسيق. يتطلب التصدير اعتماد نطاق البيانات والصلاحيات قبل تنفيذه. |

تستخدم الصفحة استعلام SQL مباشرًا عند فتحها أو تحديثها، وتعيد الطلب كل 60 ثانية أثناء ظهورها. يمكن التحقق من جودة البيانات والتسويات على نسخة اختبار مصرح بها باستخدام [فحص SSMS للقراءة فقط](../Verification/SSMS_ReadOnly_HealthCheck.sql).
